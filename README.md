# Portfólio Pessoal | Maria Eduarda

Bem-vindo(a) ao repositório do meu site de portfólio e currículo! Este projeto foi desenvolvido para apresentar minhas habilidades, experiências profissionais e um pouco sobre quem eu sou como desenvolvedora Front-end, unindo tecnologia, design e foco em experiência do usuário.

## Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web clássicas, prezando por uma interface responsiva, elegante e interativa:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização avançada com variáveis CSS, Flexbox, CSS Grid e animações suaves (transitions e keyframes).
- **JavaScript**: Lógica de interatividade (como o sistema dinâmico de abas na seção de experiências).
- **Google Fonts**: Utilização da família tipográfica [Poppins](https://fonts.google.com/specimen/Poppins) para um visual moderno.
- **Font Awesome**: Ícones vetoriais para os links de redes sociais.

## Funcionalidades e Seções

O site possui um design moderno de página única (*One Page*), facilitando a navegação. Suas principais seções são:

- **Início (Hero Section):** Apresentação curta e de impacto com foto de perfil estilizada com um leve glow em degradê.
- **Experiência:** Um sistema interativo de abas (tabs). Graças ao uso inteligente de CSS Grid e JavaScript, o usuário pode navegar pelo histórico profissional sem "pulos" indesejados na tela, mantendo a estabilidade do layout.
- **Skills:** Grade organizada dividindo as habilidades em Web Design, Frontend e Soft Skills.
- **Sobre Mim:** Um texto pessoal abordando minha trajetória na UNICAMP, vivências corporativas (Boa Vista, Enactus), contato com impacto social e também meus hobbies (videogames e filmes).
- **Contato:** Acesso rápido ao meu e-mail, LinkedIn e GitHub.
